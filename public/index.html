Пакетная обработка

Перетащите много файлов (или всю папку) — получите ZIP с чистыми копиями. Язык определяется по расширению автоматически.

📁 Перетащите файлы сюда или выберите JS, TS, Python, Java, C, C++, C#, Ruby, Go, Rust, PHP, CSS, HTML и др.

Публичный API

Лимит — 30 запросов в минуту с IP. Идеально для Discord-ботов, CI-скриптов, IDE-плагинов.

🧹 remove — удаление комментариев

POST/api/remove
curl -X POST https://codr.netlify.app/api/remove \
  -H "Content-Type: application/json" \
  -d '{"code":"# x\nprint(1)","language":"python","minify":false}'
# → {"result":"print(1)","stats":{...}}
GET/api/remove?action=languages
curl https://codr.netlify.app/api/remove?action=languages

📊 stats — статистика кода

POST/api/stats
curl -X POST https://codr.netlify.app/api/stats \
  -H "Content-Type: application/json" \
  -d '{"code":"def f():\n  # x\n  return 1","language":"python"}'
# → {"stats":{"totalLines":3,"commentLines":1,"minifiedSize":15,"minifySaving":22,...}}

💬 snippets — Discord embed

POST/api/snippets
curl -X POST https://codr.netlify.app/api/snippets \
  -H "Content-Type: application/json" \
  -d '{"code":"print(1)","language":"python","title":"Мой сниппет"}'
# → Discord embed JSON. Отправь напрямую: channel.send(response)

🔗 paste — короткая ссылка на код (24 часа)

POST/api/paste
curl -X POST https://codr.netlify.app/api/paste \
  -H "Content-Type: application/json" \
  -d '{"code":"print(1)","language":"python","ttl":86400}'
# → {"id":"abc123","url":"https://codr.netlify.app/p/abc123","expiresIn":86400}
GET/api/paste?id=abc123
curl https://codr.netlify.app/api/paste?id=abc123
# → {"id":"abc123","language":"python","code":"print(1)",...}

В Discord: !paste <код> → бот вернёт https://codr.netlify.app/p/abc123. Не засоряет чат огромным кодом. Требует Upstash Redis в env (см. health ниже).

🔬 explain — анализ кода

POST/api/explain
curl -X POST https://codr.netlify.app/api/explain \
  -H "Content-Type: application/json" \
  -d '{"code":"def f():\n    return 1","language":"python","format":"json"}'
# → {"language":"python","stats":{...},"structure":{"functions":["f"],...},"complexity":{"score":1,"grade":"A"}}

# format:"discord" вернёт готовый embed для Discord

GET/api/health

# → {"status":"ok","version":"2.1.0","storage":"ok","languages":32,"endpoints":[...]}
