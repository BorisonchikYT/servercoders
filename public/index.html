remove

удаление комментариев
POST/api/remove
curl -X POST https://codr.netlify.app/api/remove \
  -H "Content-Type: application/json" \
  -d '{"code":"# x\nprint(1)","language":"python"}'
# → {"result":"print(1)","stats":{...}}
GET/api/remove?action=languages
